# Start Syncy Care

## Fastest route

1. Extract the `syncy-care-complete.zip` archive.
2. Install Node.js 22 or newer if you do not already have it.
3. Open a terminal inside the folder that contains `package.json`.
4. Run `npm start`. No dependency installation is needed.
5. Open `http://127.0.0.1:3000` in your browser.

For Windows, you can also double-click `RUN_SYNCY_WINDOWS.bat` after installing Node. For macOS/Linux, run `bash RUN_SYNCY_MAC_LINUX.sh`.

Choose **Maria Thompson** to explore the care-plan snapshot changes, **Jordan Lee** for discharge and Amoxicillin teach-back, or **Ahmed Rahman** for respiratory education and inhaler teach-back. Use the left navigation to enter the care-team dashboard, Safety lab, and Architecture view.

**Everything shown is invented.** This is a working hackathon demo, not a verified medical or hospital-ready product. The care-team dashboard is an unprotected demonstration view. The RED question queue does not send alerts to actual nurses.

To run tests, use `npm run check`. For full documentation, see `README.md`.
